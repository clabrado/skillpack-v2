SHEET 00

The supervision loop — where /steer sits

/steer is external supervision. A goalpack fixes the user's intent; a detached steerer watches a latched worker session's live event stream and injects course-corrections back into it — until the task is delivered. The steerer is engine-agnostic: the decision engine behind it is swappable (LATCH_GROK_CMD), which is exactly what makes the same loop run cloud on one machine and local on another.

SHEET 02

Inside one decision

How a single steering decision moves through the two tiers. The pre-gate is a fixed heuristic ladder — the first condition that fires escalates; if none do, it auto-waits for free. Only escalated decisions reach the LLM, which returns one schema-constrained verdict.

0

Pre-gate — local, model-free no LLM · free

A pure Python heuristic (_pregate_escalate). It can only ever choose wait — never a real steer — so it is structurally incapable of a bad intervention. Validated against 237 real logged decisions: escalates 100% of actions and turn boundaries, skips ~63% of calls (clean mid-work waits).

Turn boundary / idle — worker finished a turn, needs direction.ESCALATE
Notification / permission pending — something is waiting on an answer.ESCALATE
Tool error / traceback — an error signal in the events.ESCALATE
Drift-signal keyword — a goalpack drift term appears in the events.ESCALATE
Stall — same tool call repeated ≥3×.ESCALATE
Clean mid-work — none of the above; worker is progressing.AUTO-WAIT
1

Engine — one LLM judgment cloud Grok · or local via LATCH_GROK_CMD

Escalated decisions get a schema-constrained call ({action, message, reasoning, evidence}). A continuing session (--session-id/--resume) gives the engine its own memory across the run. On the Mini this is cloud Grok 4.5; on the MacBook Pro it's local rtx4080. The engine returns exactly one verdict:

wait
Let the worker keep going. No inject.
steer
Type a new prompt at the next idle point.
redirect
Interrupt the current turn, re-prioritize now.
done
Objective met. End the loop, notify.
blocked
Stuck on an external dependency. Notify.

What this drawing is honest about

The Mac Mini path (pre-gate → cloud Grok) was verified live on 2026-07-18: the pre-gate logged [pregate summary mode=on] here and no LATCH_GROK_CMD override is set, so Tier-1 is cloud. That is real and confirmed from this machine.

The MacBook Pro path (pre-gate → local rtx4080) is recorded as Chris configured it on 2026-07-17 — it was not re-verified from the Mini for this document. The pre-gate being model-free, the ~63% filter rate, and the engine-swap mechanism are all read directly from client/steerer.py.

The quota fallback is designed only — no code exists yet. The three-tier judge split was floated once and dropped; it is drawn dotted precisely so no one mistakes it for something that runs.

Standing recommendation — Mac Mini

Keep the current setup. Do not add gpt-oss:20b as a judgment tier here. The pre-gate already skims every easy decision for free, so a local-model tier would be handed only the hard calls it is weakest at — which is exactly why "too weak to judge" is decisive on the Mini specifically.

"Cloud spend" here is quota, not dollars: the default engine is the flat SuperGrok subscription, so a cloud steer call costs $0 marginal until the weekly pool is exhausted (a 402 has happened once). The pre-gate's ~63% cut already stretches that pool.

The one improvement worth making is the quota fallback — local rtx4080 as a degraded-but-not-blind safety net when cloud returns 402, never as the primary tier.
